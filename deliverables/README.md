# Deliverables

Documents sent to the client, exactly as sent: one dated folder per sending,
`YYYY-MM-DD-<short-name>/` (for example `2026-10-20-feasibility-report/`),
holding the file that went out and, beside it, its source when we have one.

- A deliverable is frozen once it is sent. A corrected version is a new
  folder, and the log below says what it replaces.
- Design releases are not deliverables: a release is a frozen design
  revision and lives in the stack project (`protoboard release`, in
  `protoboard/`). When a release is handed to the client, the folder here
  holds the cover note and names the release version.
- Quotes live in `quotes/`, not here.
